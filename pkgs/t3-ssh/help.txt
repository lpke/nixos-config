T3 SSH connection
=================

Your PC keeps a shared SSH connection to the Mac open. SSH is the default
desktop T3 route, with HTTP as a backup, so remote editor access is available.
The service also forwards @LOCAL_URL@ to T3 on the Mac for health checks
and optional URL pairing.

Commands on the PC
  t3-ssh start    Start or resume the connection and tray.
  t3-ssh stop     Pause the connection, keeping the tray available.
  t3-ssh status   Show whether the connection reaches T3 on the Mac.
  t3-ssh quit     Stop the connection and close its tray icon.
  t3-ssh help     Open this file.
  t3-ssh logs     Show recent connection and tray logs.

The first T3 Code launch in each desktop login starts the connection and tray.
Closing T3 leaves them running. Later T3 launches in the same login respect
Pause and Quit. Use Start or t3-ssh start to resume. Nothing starts at boot
or login until you launch T3.

The tray icon is always visible while its service is running. Green means
the tunnel reaches T3 on the Mac. Red means paused, connecting, or an error.
Right-click it for Start, Pause, Show logs, Help, and Quit.

Use the saved connection
  1. On the Mac, open T3 Code Beta. Keep it running and keep the Mac awake.
  2. On the PC, open T3 > Settings > Environments.
  3. Enable the Mac entry, currently Luke Perich.
  4. Under Routes, keep SSH @SSH_HOST@ first and HTTP after it as a backup.
  5. Open a Mac project/thread. For a new thread, choose the Mac under Run on
     beside the message box, then choose a project or folder on the Mac.
  6. In that thread's terminal, uname -s should print Darwin.

Open in VSCode
  T3 0.1.7 needs an active SSH route or an advertised SSH editor target.
  Merely saving an alternate SSH route does not enable its editor button.
  In Settings > Environments > Luke Perich > Routes, drag SSH @SSH_HOST@
  first. Confirm it is marked In use. HTTP stays available as a backup.
  If T3 falls back to HTTP, its editor button can become unavailable.

  VSCode uses the shared SSH connection through your @SSH_HOST@ alias.
  T3's own native SSH tunnel disables connection sharing and requires a
  fresh SSH connection. If the Mac refuses new connections, follow the
  recovery steps below even if t3-ssh status is green.

Pair for the first time or renew an expired T3 token
  1. On the Mac, open T3 > Settings > Sharing & access.
     Select the Mac's local environment if there is an environment selector.
  2. Click Create link, keep the permissions needed for normal use, and click
     Create link in the dialog.
  3. In the new link's Share area, choose Copy code only. Expand Share first
     if it is collapsed. A standalone Copy code button works too.
     Keep the settings page open until pairing is finished.
  4. On the PC, open Settings > Environments > the Mac > Routes > Add route.
     If the Mac is not saved yet, use Add environment. Use the form with Host
     and Pairing code fields.
  5. Host: @LOCAL_URL@
     Pairing code: paste the code from the Mac.
  6. Click Add route, or Add environment for the first connection.
     Confirm the Mac is connected. Keep native SSH first on the desktop;
     this loopback URL is an optional route through the tunnel.

T3 saves its secret connection token automatically. It is separate from SSH.
Renewing it does not require rebuilding the tunnel. Green checks the tunnel,
not the token: T3 can still ask you to pair again when its permission expires.

If the connection fails
  Run t3-ssh status and t3-ssh logs on the PC.
  Check that T3 is open on the Mac and that the Mac is awake and reachable.
  Try ssh @SSH_HOST@ from a PC terminal and complete authentication if needed.
  Then run t3-ssh start.

If SSH is disabled on the Mac, run these in a Mac Terminal using an account
with permission to administer it:

  sudo systemsetup -setremotelogin on
  sudo dseditgroup -o edit -a luke -t user com.apple.access_ssh

A dropped network connection, reboot, server policy, or unavailable SSH key
can require a fresh login. This service retries while started, but cannot
make an SSH connection survive those events.
