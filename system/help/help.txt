NixOS Custom Help
=================

Core
  help                         Show this custom command list.
  bnix                         Rebuild with guarded CUDA Ollama selection.
  bnix status                  Show current Ollama mode, service status, and CUDA readiness.
  bnix cpu                     Rebuild CPU Ollama config. Alias: --cpu.
  bnix cuda                    Rebuild CUDA Ollama config without readiness prompt. Alias: --cuda.
  lnix                         List NixOS system generations.
  dnix                         Garbage collect old Nix store generations.
  update-helium                Update the pinned Helium version and hash.
  update-postman               Update the pinned Postman version and hash.

Services
  xrs                          Restart the user xremap service.
  wrs                          Reload the wireless kernel module.
  prs                          Restart Piper, libratbag autostart, and ratbagd.
  ars                          Restart custom audio services.

Synergy Mac Keys
  mac-keys                     Show SSH, focused Mac app, and keyboard mapping status.
  mac-keys start               Start app detection with one SSH connection attempt.
  mac-keys stop                Stop detection; keep SSH cached and preserve Mac terminal Ctrl keys.
  mac-keys retry               Retry SSH once after enabling access on the Mac.
  mac-keys logs                Show controller, tray, and SSH logs.
  mac-keys --help              Show commands and Mac SSH recovery steps.

Audio
  audio                        Entrypoint to all custom audio commands. Run alone for help.
  audio ** help                Every command and sub-command can be followed with `help`.
  audio status                 Show readable custom audio overview.
  audio list                   List PipeWire nodes and WirePlumber devices.
  audio restart                Restart PipeWire stack and custom audio services.
  audio loopback               Manage configured PipeWire loopbacks.
  audio locks                  Manage configured software volume locks.
  audio gain                   Manage configured ALSA hardware gain targets.

Cooling
  nzxt-grid-v2-status          Print NZXT Grid+ V2 fan channel status.

Display
  display-brightness-toggle     Fade primary display to black at 0%; restore at 100% brightness.

Photo Tools
  adobe-dng-converter          Launch Adobe DNG Converter via Wine.
  convert-dng                  Convert DNG files with the configured wrapper.

Other
  cmhelp                       Show non-NixOS chezmoi help.
