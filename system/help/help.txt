NixOS Custom Help
=================

Core
  help                         Show this custom command list.
  bnix                         Rebuild and switch this NixOS flake.
  lnix                         List NixOS system generations.
  dnix                         Garbage collect old Nix store generations.

Services
  xrs                          Restart the user xremap service.
  wrs                          Reload the wireless kernel module.
  prs                          Restart Piper, libratbag autostart, and ratbagd.

Audio
  audio-loopback-status        Show managed loopbacks and unmanaged PipeWire loopbacks.
  audio-loopback-rebind        Rebind active managed loopbacks to current inputs/outputs.
  audio-loopback-output-toggle Toggle current input to current output loopback.
  audio-loopback-cubilux-toggle Toggle current input to Cubilux loopback.
  loopbacks                   Disabled by default; enable with toggle commands.
  audio-volume-lock-status     Show enforced software PipeWire volume locks.
  volume locks                 Configure in services.pipewire.audioVolumeLock.
  nzxt-mic-gain                Show or set NZXT USB MIC hardware gain percent (`nzxt-mic-gain <n>`; decimals allowed).
  NZXT USB MIC volume          Soft mixer in WirePlumber keeps hardware knobs free.
  nzxt-mic-gain-status         Show NZXT USB MIC hardware gain knob value.
  AirPods headset audio        Configure in services.pipewire.wireplumber.extraConfig.

Cooling
  nzxt-grid-v2-status          Print NZXT Grid+ V2 fan channel status.

Photo Tools
  adobe-dng-converter          Launch Adobe DNG Converter via Wine.
  convert-dng                  Convert DNG files with the configured wrapper.

Config Files
  system/configuration.nix     Main user-facing NixOS settings.
  system/custom-options.nix    Local NixOS option extensions.
  system/audio/routing.nix     Audio routing module logic.
  system/audio/volume-lock.nix Audio volume lock service logic.
  system/browser/chromium-flags.nix Shared Chromium browser flag logic.
  system/browser/webrtc-audio.nix Browser WebRTC input-volume fix.
  system/help/help.txt         This help text.
  system/fan-control/config.nix Fan curve and sensor mapping settings.
