NixOS Custom Help
=================

Core
  help                         Show this custom command list.
  bnix                         Rebuild with automatic CPU/CUDA Ollama selection.
  bnix status                  Show current Ollama mode, service status, and CUDA readiness.
  bnix cpu                     Rebuild with CPU Ollama.
  bnix cuda                    Rebuild with CUDA Ollama without a readiness prompt.
  bnix help                    Show all rebuild options.
  lnix                         List NixOS system generations.
  dnix                         Remove generations older than 14 days and collect unused store paths.
  update-helium                Update the pinned Helium version and hash.
  update-postman               Update the pinned Postman version and hash.
  t3code                       Launch T3 Code; use Settings > About for stable updates.
  t3-tray show                 Show the shared SSH and Tailscale tray.
  t3-tray quit                 Hide the shared tray, keeping both connections running.
  t3-ssh start                 Start or resume SSH and show the shared T3 tray.
  t3-ssh stop                  Pause the connection and keep its tray controls.
  t3-ssh status                Show connection health.
  t3-ssh quit                  Stop SSH, leaving the shared T3 tray available.
  t3-ssh help                  Open pairing and connection instructions.
  t3-ssh logs                  Show connection and tray logs.
  t3-tailscale start           Restore the T3 VPN route and show its tray.
  t3-tailscale stop            Pause the T3 VPN route, keeping tray controls.
  t3-tailscale status          Check gateway readiness and Mac T3 identity.
  t3-tailscale quit            Pause the T3 VPN route, leaving the shared T3 tray.
  t3-tailscale help            Open phone pairing and gateway instructions.
  t3-tailscale logs            Show gateway and tray logs.

Services
  xrs                          Restart xremap and restore current Synergy Mac mappings.
  wrs                          Reload the wireless kernel module.
  prs                          Restart Piper, libratbag autostart, and ratbagd.
  ars                          Restart custom audio services.

Synergy
  synergy-keys                 Show Synergy screen and keyboard mapping status.
  synergy-keys pause           Pause keyboard mappings and restore Linux mode.
  synergy-keys resume          Resume automatic keyboard mappings.
  synergy-keys synergy pause   Pause Synergy sharing.
  synergy-keys synergy resume  Resume Synergy sharing.
  synergy-keys inspect         Inspect shortcut inputs, transport, and Mac app outcomes.
  synergy-keys refresh         Refresh local screen detection and mappings.
  synergy-keys logs            Show screen-controller and tray logs.
  synergy-keys --help          Show keyboard controller commands.

Audio
  audio                        Show audio commands; append help to a subcommand for details.
  audio status                 Show readable custom audio overview.
  audio list                   List PipeWire nodes and WirePlumber devices.
  audio restart                Restart PipeWire stack and custom audio services.
  audio loopback               Manage configured PipeWire loopbacks.
  audio locks                  Manage configured software volume locks.
  audio gain                   Manage configured ALSA hardware gain targets.

Cooling
  nzxt-grid-v2-status          Print NZXT Grid+ V2 fan channel status.

Display
  display-brightness-toggle    Black out the primary display or restore full brightness.

Photo Tools
  adobe-dng-converter          Launch Adobe DNG Converter via Wine.
  convert-dng                  Convert DNG files with the configured wrapper.
  adobe-photoshop setup        Download and open the Creative Cloud installer.
  adobe-photoshop cloud        Open Creative Cloud to install licensed Adobe apps.
  adobe-creative-cloud         Open the installed Creative Cloud desktop app.
  adobe-photoshop run          Open installed Photoshop.
  adobe-photoshop repair       Repair Adobe compatibility fonts and runtimes.
  adobe-photoshop scale N      Set Adobe UI size in percent; relaunch Adobe to apply.
  adobe-photoshop file-picker kde|wine  Prefer KDE or use Wine file dialogs.
  adobe-photoshop stop         Close all Adobe apps and background services; save work first.
  adobe-photoshop status       Show Adobe installation status and settings.
  adobe-photoshop --help       Show all Adobe launcher options.

Other
  cmhelp                       Show shared dotfile commands and shortcuts.
